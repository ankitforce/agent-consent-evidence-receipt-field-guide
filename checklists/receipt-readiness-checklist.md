# Receipt Readiness Checklist

Use this before declaring an agent workflow complete.

- [ ] The user's request is summarized in plain language.
- [ ] Consent or approval status is explicit.
- [ ] Permission scope and constraints are listed.
- [ ] Actor, model, runtime, and delegates are named.
- [ ] Tools and systems touched are listed.
- [ ] Material claims link to evidence.
- [ ] Community or weak evidence is labelled as such.
- [ ] Mutations and created artifacts are listed.
- [ ] Verification checks are recorded as passed, failed, blocked, or not run.
- [ ] Residual risks are visible to the human reviewer.
- [ ] No secrets, cookies, private URLs, or local-only paths are included.
